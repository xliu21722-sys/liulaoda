# 刘老大

一个为教程创作者制作的原生 Mac 截图与录屏工具。通过菜单栏操作，截取、剪裁、命名，再保存或复制素材。

## 下载应用

**[前往 Releases 下载 Mac 安装包](https://github.com/xliu21722-sys/liulaoda/releases/latest)**

- 推荐下载 `Liulaoda-4.9-arm64.dmg`，打开后把“刘老大”拖入“Applications”。
- 也提供 ZIP，解压后即可得到“刘老大.app”。普通用户无需安装开发工具或运行构建脚本。
- 当前版本适用于 **Apple Silicon Mac（M1 及更新芯片）**，最低系统声明为 macOS 15；已在 MacBook Air M3、macOS Tahoe 26.2 上实测。Intel Mac 尚未提供构建。
- 此版本使用本地临时签名，**尚未经过 Apple 开发者签名与公证**。其他 Mac 下载后可能出现开发者验证提示，请遵循 macOS 的安全确认流程。

## 使用

1. 打开应用，选择素材保存位置：本地项目文件夹、桌面或 Eagle 素材库。
2. 在菜单栏选择“截屏”“录屏”或“快速录屏”。选择框选模式时，拖动鼠标确定区域；录屏也可点击上次选区开始。
3. 录制时，细蓝框标记录制范围，框外变暗；旁边显示时长和结束按钮。
4. 普通截图、录屏结束后进入预览，可调整画面保留范围；视频可剪头尾，或加入多个片段后分别导出。
5. 填写备注后点击“保存”，或点击“复制”把当前剪裁结果放入剪贴板。快速录屏结束后直接保存，不进入预览。

未命名的普通素材按 `001_未命名.png`、`002_未命名.mp4` 这样的方式编号。保存遇到同名文件时不会覆盖旧文件。

### 声音与权限

麦克风和电脑声音是两个独立开关，默认关闭。macOS 会管理屏幕录制与麦克风权限；请仅在实际使用时按系统提示授权。第一次调整权限后，系统可能要求重新打开应用。

### Eagle

需要本机 Eagle 保持打开。应用通过 `127.0.0.1:41595` 的本地 API 读取文件夹并导入素材；选择目标文件夹后再保存或快速录屏。

### 复制与本地处理

截图以 PNG/TIFF 数据写入系统剪贴板。视频复制需要独立的临时交接文件，以便在预览关闭后继续粘贴；不会写入桌面、项目文件夹或 Eagle。剪贴板替换后会清理该缓存，应用退出遗留的缓存会在后续复制时清理过期项目。接收软件需要支持相应的图片或视频粘贴格式。

素材在本机处理，应用没有上传服务，也不提供自动隐私打码。使用前请自行检查录制画面。

## 开发与打包

以下仅供维护者使用。构建需要 Mac、Xcode Command Line Tools，以及支持当前源码所用 API 的 macOS SDK；生成发布包另需 Python 3 标准库。

```sh
./scripts/build.sh
./scripts/package.sh
```

构建产物位于 `build/刘老大.app`；发布包和 SHA-256 校验文件位于 `dist/`。运行时不依赖 Python、Node.js 或第三方包。核心使用 SwiftUI、AppKit、ScreenCaptureKit 和 AVFoundation。

目录：

```text
Sources/TutorialCapture/   原生界面、采集、视频导出、Eagle 与剪贴板
Resources/                应用图标
scripts/build.sh          本机构建与临时签名
scripts/package.sh        生成 DMG、ZIP 和校验文件
scripts/verify-media.swift 媒体处理回归验证
Info.plist                应用版本与权限声明
```
